# bend-ssz

SSZ serialization primitives for Bend 2 on the Lean Ethereum formats.

## Features

- SSZ roots over the pinned [adust09/bend-merkle-tree](https://github.com/adust09/bend-merkle-tree) library, with the SHA-256 pair hash bound by this layer instead of staying hash-generic;
- `Uint64` and `Boolean` chunk encoding, length mixing, capped list roots, 52-byte public-key roots;
- SSZ `BitList` packing into bytes, byte-chunk padding, and capacity-bounded bitlist roots;
- golden vectors generated by an independent Python reference (`tests/ssz_golden.py`, stdlib only).

## Requirements

- Bend `2.0.34`
- `git` to fetch the pinned merkle-tree checkout
- Python `3.10+` for regenerating test vectors

## Install

This library imports the pinned merkle-tree checkout relatively, like the Lean
Ethereum clients do:

```sh
git clone https://github.com/adust09/bend-ssz.git vendor/bend-ssz
git -C vendor/bend-ssz checkout <commit-or-tag>
./scripts/bootstrap.sh
```

Then import the modules relative to your Bend entry point:

```bend
import ../vendor/bend-ssz/src/ssz.bend as Ssz
```

`scripts/bootstrap.sh` pins `bend-merkle-tree` at the audited commit under
`deps/` and refuses to run against a modified checkout. Bump `MERKLE_PIN`
in the script explicitly when adopting a new release.

## Test

```sh
./scripts/bootstrap.sh
./scripts/test.sh
```

The conformance test compares Bend results with the independent Python
reference for chunk encodings, bitlist packing, byte chunking, list roots,
and capacity-bounded bitlist roots.
